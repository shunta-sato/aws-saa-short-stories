# 世界線: フォトリム(photorim)

写真・動画共有サービスを運営する中堅企業「フォトリム社」を舞台とした世界線。シリーズ第1作。

## 登場人物

- **瀬名美咲(せな・みさき)**: 主人公。インフラエンジニア。優秀だが経験が浅く、失敗から学ぶ。三人称で描く。
- **堂島(どうじま)**: 先輩エンジニア。要点を突く助言役。「数字を見ろ」「要件語を読め」が口癖。説教臭くしない。
- **矢吹(やぶき)**: 買収先・東雲アーカイブズ社の古参エンジニア(50代)。元クラウド懐疑派のテープ職人。DC閉鎖後、フォトリムのクラウド運用チームに合流。オンプレ時代の比喩で本質を言い当てる役回り。
- **青柳(あおやぎ)**: 新人。読者の代弁者として素朴な質問をする。誤削除事故の前科(第5編)。
- **狩野(かのう)**: 法務部。理詰め。「監査に書けるか」が判断基準。

## 会社・サービス設定

- フォトリム: 写真・動画共有サービス。ユーザー数成長中。動画機能が当たり、有料会員と単発課金(決済系)を開始。
- 東雲(しののめ)アーカイブズ社: 買収した映像アーカイブ会社。オンプレDC(テープライブラリ、NetApp、ZFS、レンダリングファーム)を保有していたが、移行完了しDC閉鎖済み。
- リージョン: 本番=東京、DR=大阪。

## 年表(既刊の出来事)

| 編 | 出来事・確立した構成 |
|---|---|
| storage/01 | ストレージコスト爆発→ライフサイクル設計。Deep Archive誤投入事件(12時間待ち)。動画機能開始、編集チームはEFS+gp3 |
| storage/02 | メタデータDBをgp2→gp3移行。決済DBはio2(20,000 IOPS)。分析ログはst1/sc1。トランスコード一時領域はインスタンスストア。AWS Backupで一元管理(東京→大阪コピー) |
| storage/03 | 東雲社買収・移行開始。EFS(Standard/IA/One Zone、Elasticスループット)、FSx 4種の割当。矢吹が軟化 |
| storage/04 | Snowball Edge×複数台で2PB移送、Snowconeでロケ先回収、Tape Gateway/File Gateway/Volume Gateway 2種。DC閉鎖、矢吹が合流 |
| storage/05 | 青柳の誤削除→バージョニングで復旧。Object Lock(Compliance/Governance/Legal Hold)、SRR(別アカウント隔離)+CRR(大阪)+RTC。Glacier 3階層の仕分け |
| resilience_and_dr/01 | ゲームデー実施。DR4戦略の割当(決済=ウォームスタンバイ、閲覧=パイロットライト、社内=バックアップ&リストア)。AMI大阪未コピー事件(実測RTO37分)。SPOF(NAT 1AZ・踏み台1台)は未解消=ネットワーク編へのフック |

## 未回収の伏線
