# 幕間 通らなかった記録 — VPCフローログ

*SAA-C03 短編小説集 / S2幕間01 — 用語集外の頻出トピック補強(ショートショート)*

---

NACLの一件から、次の輪番までの宿題がひとつ残っていた。フローログ。あの20分に実際に何が弾かれていたのか、記録で言える状態にする——堂島美咲が自分で切った約束だ。

作業は青柳凛と二人でやった。あの日の障害報告書を書いたのは青柳で、彼は影響の欄に書いた「破棄されたと推測される」の一語を、まだ根に持っているらしかった。

「障害報告書に『推測』って書くの、悔しいですね」

「悔しいまま覚えておくといいやつ」美咲は設定画面を開いた。「今日入れるのは、その推測を次から事実にする装置」

VPCフローログの有効化そのものは、拍子抜けするほど簡単だった。取れる単位は三つ——VPC全体、サブネット、ENI。まずVPC全体で網を張り、深掘りのときにENIで絞る。送り先は、すぐ検索してアラートに繋ぐならCloudWatch Logs、安く長く貯めて後で分析するならS3。記録される行には、送信元と宛先、ポート、バイト数、そして判定——ACCEPTかREJECTか。

有効化を終えた青柳は、さっそく過去ログを検索しようとして、数秒、黙った。

「……あの日のログ、見られると思ってました」

「録画装置は、設置した日からしか録れない。あの20分は永遠に推測のまま。——それが今日いちばんの学びでいいと思う」

青柳の「推測される」は、書き直せないまま残った。書き直せないことが、この装置を早く入れるべきだった理由のすべてだった。

---

フローログが最初の仕事をしたのは、事件のない木曜だった。

REJECTの行を眺めていた青柳が、妙な規則性を見つけた。5分おきに、寸分違わぬ間隔で、同じプライベートIPから外の同じ宛先へ——弾かれ続けている通信がある。何か月も、律儀に。

「クリプトマイナーだったりして」青柳の目が光った。「マルウェアが外の司令サーバーに——」

「賭ける? 私は監視SaaSの残骸に一票。契約が切れたエージェントが、もういないご主人を呼び続けてるだけ」

「乗ります。缶コーヒー一本」

発信元をENIから辿ると、東雲から引き継いだ例のバッチサーバーだった。青柳が中に入ってcronを開き、二人同時に首をかしげた。犯人のスクリプト名は、マルウェアにしては行儀がよすぎた。

`rack_mimawari.sh`

中身は短かった。5分おきに、どこかのIPへ、ラックの温度と電源状態を問い合わせに行く。宛先のIPは——大阪の、あのデータセンターの監視サーバー。今はもう、更地の住所だった。

美咲は少し迷ってから、輪番チャンネルではなく、矢吹智弘の席へ直接持っていった。画面を見た矢吹は、数秒、黙った。それから、誰も聞いたことのない声で言った。

「……それ、俺や」

DCの深夜、居眠りせずにラックの熱を見張るために、30年前の矢吹青年が書いた見回りスクリプトだという。代替わりしながらあちこちのサーバーに植え継がれ、閉鎖のとき全部止めたはずが、移行したバッチサーバーの中に一本だけ生き残っていた。主のいない住所へ、5分おきに「異常ないか」と聞きに行き、応答のない夜を何か月も続けていた。

「消しときましょうか」と青柳が言うと、矢吹は首を振った。

「いや。俺が消す」ログイン一つ、コマンド一つの間、誰も口を利かなかった。「——自分で書いたもんは、自分で看取るんや」

それから矢吹は、何事もなかったように伝票のような顔に戻り、「賭けはどうなったんや」と聞いた。マイナー説も残骸説も外れなので、缶コーヒーは矢吹に行った。ブラックかと思いきや、選んだのはいちばん甘いミルクセーキで、青柳は自販機の前で吹き出しそうになるのを堪えていた。

「記録に映るのは、通信だけじゃないんですね」帰り道、青柳が言った。「人の癖まで映ってました」

夜、青柳は障害報告書のフォーマットに新しい欄をひとつ足した。「影響範囲(フローログ確認済み/未確認)」。それから輪番チャンネルに、今日の一件を三行で報告した。最後の一行だけ、報告書らしくなかった。

## 補講コラム — VPCフローログ

**VPC内の通信の「通った/弾かれた」を記録するメタデータのログ。** VPC・サブネット・ENIの3単位で有効化でき、送信元/宛先IP・ポート・プロトコル・バイト数・ACCEPT/REJECTが記録される。送信先はCloudWatch Logs(即時検索・アラート向き)またはS3(長期保存・後日分析向き)。

要点は三つ。①**有効化以前の通信は遡れない**——装置は事件の前に仕込む。②見えるのはメタデータだけで、**パケットの中身は見えない**(中身が要るならトラフィックミラーリング)。③「誰がAPIで設定を変えたか」はCloudTrail、「通信が通ったか」はフローログ——この混同が定番のひっかけ。「SG/NACLが通信をブロックしていないか確認したい」という問題文が出たら、答えはほぼフローログ。

## 確認クイズ

1. 「特定のEC2への通信がセキュリティグループかNACLで拒否されていないか調査したい。ただし過去1週間分も見たい」——何が必要で、何に注意すべきか?
   → VPCフローログ(ENIまたはサブネット単位)でREJECTの記録を確認する。ただしフローログは有効化以降の通信しか記録しないため、過去分は事前に有効化されていた場合にのみ遡れる。パケットの中身は記録されない点、API操作の記録はCloudTrailの担当である点にも注意。
