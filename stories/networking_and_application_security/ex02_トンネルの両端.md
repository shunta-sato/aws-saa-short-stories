# 幕間 トンネルの両端 — VGWとカスタマーゲートウェイ

*SAA-C03 短編小説集 / S2幕間02 — 用語集外の頻出トピック補強(ショートショート)*

---

東雲の残拠点——大阪郊外の倉庫事務所を閉域で繋ぐ日、役割を決めたのは矢吹智弘だった。

「今日は逆や。堂島さんが倉庫のルーターの前、わしがコンソール。——たまには両端を入れ替えんと、地図の裏が読めへんで」

というわけで、堂島美咲は倉庫事務所の配線棚の前に立っている。目の前には東雲時代からのルーター。側面に古いテプラが貼ってある。「勝手に再起動せんこと。——矢吹」。棚の内側には、手描きの配線図がラミネートで留めてあった。字は、テプラと同じだった。

耳のイヤホンから、神戸の矢吹の声がする。通話は繋ぎっぱなしだ。

「ほな、おさらいや。AWS側の受け口が**Virtual Private Gateway**——VPCに付ける仮想の門や。ほんで、わしが今からAWSに登録する**Customer Gateway**いうのは、何や?」

「そのルーターの『登録情報』です。実体はAWSの中にはない。実体は——」美咲は目の前の機械を軽く叩いた。「今、私の目の前にいます」

「そや。カスタマーゲートウェイをAWSのリソースやと思い込むんが、いちばんよくある勘違いや。AWSにあるんは名刺だけ。本人は現場におる」

コンソール側から、キーを打つ音が聞こえてくる。VPN接続の作成、トンネル設定のダウンロード。その手つきが、妙に淀みない。

「矢吹さん……画面、見ないで打ってません?」

数秒、間があった。「……夜中にな、あんたらの読み合わせの議事録と、教材で練習しとったんや。五十八の夜更かしや。笑いたければ笑え」

「笑いません」美咲は笑いながら言った。一年前、値踏みの目でクラウドを睨んでいた人が、夜中に一人でコンソールを触っている。その画は、笑うようなものではなかった。

「設定は2本ぶん来とるぞ」と矢吹。「トンネルは1本のVPN接続につき2本張られる。**2本で1組や。片方は保険やないで、仕様や**。AWS側の出口が別々になっとって、向こうの都合で片方が落ちても、もう片方で繋がり続ける」

「このルーター、BGPは話せますか」

「無理やな、その世代は。動的にルートを交換するBGPが使えんときは、静的ルーティングや。行き先をこっちの手で書く。台数が少ない拠点なら、それで十分やしな」

---

設定を流し込み、トンネルを起動した。コンソール側の矢吹が状態を読み上げる。「1本目——DOWN。2本目——DOWN。……あかんな」

「こっちのログを見ます」美咲はルーターに向き直った。AWSの画面は「相手が応答しない」としか言わない。理由は、いつも向こう端にある。ログを遡ると、鍵交換の段階で落ちていた。事前共有鍵の不一致——ではない。送信元のIPが、登録したものと違う。

「矢吹さん、これ、ルーターの手前に何かいます。回線業者の装置でNATされてる。登録した固定IPじゃなくて、別の顔で出てます」

「倉庫の回線、去年の契約変更で機器が変わっとったな……。ほな、業者の装置をブリッジに切り替えるか、NAT越えの設定や。——見えたか、堂島さん。**AWSの画面だけでは、半分しか見えへん**。トンネルの向こう端は、向こうの機械や。今日、両端に人を置いた理由がそれや」

回線装置の設定を直し、鍵交換が通り、1本目がUPになった。数分後、2本目もUPになった。

「そっちはどうや」

「両方、上がってます」美咲はルーターのランプを見ながら答えた。「そっちは」

「両方、緑や」電話の向こうで、矢吹が小さく息をつくのが聞こえた。「……東雲の看板下ろしてから、この倉庫はずっと『残り物』扱いやった。今日からまた、地図に載る建物や」

帰りぎわ、美咲は棚の内側のラミネートの配線図を写真に撮った。描いた人間しか読めない地図、と本人は言っていたが、今日はそれに随分助けられた。読まれる日が来るまで地図を貼っておくのも、地図の仕事のうちらしい。

## 補講コラム — Virtual Private Gateway / Customer Gateway

**Site-to-Site VPNの両端の名前。AWS側の受け口がVirtual Private Gateway(VGW)、拠点側の登録情報がCustomer Gateway(CGW)。** VGWはVPCにアタッチする仮想の門(構成によってはTransit Gatewayが受け口になる)。CGWは「AWS上に作るリソース」だが実体は拠点のルーターで、AWSにあるのは名刺(IPアドレスやASN)だけ——ここの取り違えが定番のひっかけ。

あわせて三点。①トンネルは1接続につき**2本**張られる(AWS側の冗長。片方は保険ではなく仕様)。②拠点ルーターがBGPを話せれば動的ルーティング、話せなければ静的。③開通しないときの原因の半分は拠点側(鍵・NAT越え・機器)にある——AWSのコンソールだけでは切り分けが完結しない。

## 確認クイズ

1. Site-to-Site VPNを構成する際、Customer Gatewayとして「AWS側に配置する機器」を選定しようとしている。この理解の誤りと、正しい構成は?
   → Customer GatewayはAWS上に作る「拠点側ルーターの登録情報」であり、AWS側に置く機器ではない。AWS側の終端はVirtual Private Gateway(またはTransit Gateway)で、拠点側の実体はオンプレのルーター。1つのVPN接続には冗長化のためトンネルが2本張られる。
