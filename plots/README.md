# plots/ — プロット(執筆設計図)

各エピソードの執筆前プロットを置くフォルダ。命名は `<family略称>-<NN>_<タイトル案>.md`。

- シリーズ全体の構成・用語割当・伏線マップ: [series-plan.md](series-plan.md)
- プロットの位置付け: 執筆者(Opus)への指示書。執筆済み本文と矛盾した場合は本文と universe.md が優先し、プロットは追従修正する。
- 各プロットの必須要素: メタデータ(family/episode/terms/universe参照)、あらすじ、ビート(起承転結)、必須シーン、伏線(張る/回収)、技術ポイント(具体値)、書いてはいけないこと。
- 執筆フロー: プロット確定 → Opus執筆 → 監督二段階レビュー(writing-guide参照)→ 修正ループ → カバレッジ検証 → PR。

| 状態 | 意味 |
|---|---|
| draft | 監督検討中 |
| ready | 執筆に出せる |
| written | 本文執筆済み(プロットはアーカイブ扱い) |
