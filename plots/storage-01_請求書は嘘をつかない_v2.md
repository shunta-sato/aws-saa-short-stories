## 構造方針(v2.2: バズによる顕在化+遅れてくるヒーロー)

- **コスト構造の正典**: 写真時代のAWS費用はコンピューティング(サムネイル生成・画像処理)と配信転送が主役で、S3保存費は全体の2割弱の「静かな行」。全データがStandardなのは皆が知る事実であり、問題ではなかったから順位が上がらなかっただけ。
- **瀬名の不在(本話の構造の鍵)**: 動画ベータの設計期間〜第一章、瀬名は「東京の実家の事情」で長期不在。**詳細は一切説明しない**(美咲も知らない。「しばらく東京に行く」だけ)。唯一のSAが抜けた数か月で設計レビューの網に穴が空いた——**human SPOFの最初の前震**(S3⑤・S8で悪化する事情の、説明されない初出)。
- **美咲の立場**: 31歳・入社2年(クラウドは実質3年目)。動画ベータは彼女が初めてインフラ主担当として一人で設計した新サービス。一杯一杯の中、保存は慣例どおりStandardに(判断ですらなく、考える順番が回ってこなかった)。オフページの経営層が「保存設計はGA前に見直し」を条件にGoサイン——条件は議事録の一行になり、バズが計画を追い越した。
- **急性**: ベータ3週目、城戸が日次の単価監視で「小さな違和感」(1GB単価が見積もりの2.4倍。総額は数%)。原因はアップロード再送嵐・遠距離転送・編集往復——ストレージクラスの話ではない。**美咲がひとりで主対応**(瀬名不在のまま)。
- **転回の鍵=バズ**: 招待制一般枠がSNSで話題化(有名人の挙式動画)。枠を二度拡大、流入は想定の20倍。コンテンツ単価は写真の約1000倍(4MB→3〜8GB)。**急性対応で受け入れ口を直したからこそ流入が加速する**(直した蛇口が樽を溢れさせる)。
- **慢性の顕在化と、遅れてくるヒーロー**: 静かだった保存の行が総額でいちばん速く動く行に変わり、外挿(流入継続+GA+7年保管規約)でユニットエコノミクスが逆転。美咲が一人で抱えて溺れかけたところへ、**瀬名が東京から戻る**。ただし瀬名は答えを出さない——問いと検算で美咲にやらせ切り、**裏では関係各所への根回しで批判の風を止めている**(だから美咲に直接数字を突きつけるのは城戸だけ。このことを美咲は終盤まで知らない/気づくのは一瞬の描写のみ)。
- **責任の質(誰も無能にしない)**: 美咲=慣例に流れた(初担当で一杯一杯。恥は省略しない)。瀬名=不在だった(不可抗力。だが「戻ってから確かめなかった数週間」は自分の分として引き受ける)。経営層=条件付き承認の条件を追わなかった(オフページ)。城戸=単価の妥当性をベータ前に詰めなかった、を自分の分に。
- **週次の時計**: 6週間を「傾向1週→確定1週→修正1週→テスト1週→予備1週→GA週」で刻む。章の進行が週次レビューで時を刻む(旧稿の「一か月」連呼を廃止)。
- **Staging/本番の規律**: ベータ設計時のStagingシミュレーションは「綺麗なテストデータ」で行われ、実ユーザーの失敗再送パターンも、本番3年分のプレフィックスの多様性も再現していなかった——急性(単価2.4倍)の見逃しと、第四章の誤投入事件の**共通の根**として一本の線にする。
- **デッドライン**: GA日。式場契約と招待待ちの圧力で動かせない。
- **トーン**: バズも危機も煽情しない。ダッシュボードの傾き・招待待ちの人数・静かなオフィスの温度差で語る。

## 章別ビート

### 第一章 二・四倍(約4,500字)— 急性: 一人きりの違和感

1. 冒頭の問い(1ページ目): 動画ベータ3週目の朝、城戸からのSlack——「動画ベータの原価、1GBあたりで見積もりの**2.4倍**ペースです。額はまだ小さい。小さいうちに、見てもらえますか」。騒ぎではなく違和感から。
2. 不在の確立: 隣の島の、空いたままの席。瀬名は二か月前から東京——「実家のことで、しばらく」とだけ言って発った(**理由は書かない。美咲も聞いていない**)。誰もが瀬名の席に相談に行く会社で、その席が空いている。美咲は初めて、一人で新サービスのインフラを背負っている。
3. 回想(厚め・ここに集約): 前職SIerのサーバールームと終電/求人票の一行「取り出せる形で残す」/瀬名の面接「そのとき、何の数字を見て判断した?」/入社後、クラウドは実質ここからの3年目であること/動画ベータのアサイン時、瀬名が出発前に言い残した一言(助言ではなく「数字はおまえが一番近くで見ることになる」程度の、後から効く言葉)。
4. 原因分解(美咲が一人で。問いかける瀬名はいない——その不便さを書く):
   - **再送の嵐**: 8GB動画のPutObject一発上げ→失敗→頭から再送。→**マルチパートアップロード**(5GB超は必須・並列・失敗パートのみ再送)+未完了パートの自動破棄(**ライフサイクル**初出)。
   - **太平洋の距離**: ハワイ挙式の納品転送→**Transfer Acceleration**。
   - **編集スタジオの往復**: ローカルコピー往復→**EFS**共有+**gp3**スクラッチ。**EBS Multi-Attach**はio1/io2限定・同一AZ・クラスタFS前提で棄却。
   - 見逃しの根の提示(さりげなく): Stagingの負荷試験は綺麗なテスト動画で通っていた。実ユーザーの回線で起きる失敗再送は、Stagingでは一度も起きなかった。
5. 土曜の結婚式という小さな時計(納品期限1つ。間に合う。派手にしない)。
6. 背景に最初の気配: 招待制一般枠で、ある挙式動画が静かに話題になり始めている。
7. 章末: 単価1.1倍まで収束、火は消えた——その夜、招待待ちリストの数字がひと桁増えた通知(第二章への引き)。

### 第二章 静かだった行(約4,500字)— バズ、顕在化、そして瀬名が戻る

1. バズの実相(節度): 招待枠を二度拡大。流入は想定の20倍。お祝いムードのオフィスで、美咲と城戸だけが別のグラフを見ている。アップロード成功率は高い(第一章の成果)。**直した蛇口から、水が想定の20倍流れ込んでいる**。
2. 城戸の観測(転換点): 「跳ねた行は皆が見ます。動かん行は、誰も見ません。——その動かんかった行が、いま、うちでいちばん速う動いてます」。動画はすべて写真と同じく**S3 Standard**へ。単価1000倍の流入が、三年間問題にならなかった「全部Standard」を初めて経営の数字に変えた。
3. 外挿が危機を作る(経営会議): 城戸の三本の線——①流入ペース(招待枠はもう閉じられない)②GA後の成長予測③**7年保管規約**(式場プランの契約開始時からある条項。静止画なら誤差だったが、動画×Standardでは「数年目にストレージ費用だけで経営が立たなくなる線」として初めて牙を剥く——城戸がこの線だけ色を変えて引く)。**このままGAすれば、伸びるほど現金が減る**。値上げ(記録を人質=ブランド死)・約束削減(狩野が拒否)を棄却し、「保存原価を設計で半減する」一本道。GAまで6週間。議事録の一行——「保存設計はGA前に見直し」——が読み上げられる。書いたのは数か月前の自分たちで、追わなかったのも自分たちだ。
4. 美咲が沈む夜(恥は省略しない): 慣例でStandardにしたのは自分。条件の一行を覚えていたのに、順番が回ってこなかった。一人で抱えて、手が止まる。
5. **瀬名が戻る(遅れてくるヒーロー)**: 翌朝、空いていた席に鞄がある。「留守の間の請求書を読んだ。——どこから話す?」。東京の件は語らない(美咲も聞かない)。瀬名は答えを出さず、問いを三つだけ置く(頻度・待てる時間・再作成可否の原型)。
6. 責任の検分(短く、全員の分): 美咲「慣例で置きました。私の判断です」/瀬名「いなかったのは仕方がない。戻って数週間、請求書を開かなかったのはおれの分だ」/城戸「単価の検算をベータ前にやるべきでした」。誰も互いを責めない。各自が自分の分だけ引き受ける。
7. 章末: 週次の時計の宣言(傾向1週→確定1週→修正1週→テスト1週→予備1週→GA週)。役割分担——7年保管データ(一番重い行李)は**意図的に最後へ回す**(美咲「一番重いのは、最後に運びます」。皆が意識している、を一行で示す)。狩野の口から高知の引き合い(伏線)。守屋が末席で議事録。

### 第三章 読まれ方の地図(約4,500字)— 証明の章: 仮説を数字にしてから、腹を括る

**物語的位置付け**: 第二章の終わりは「半減する」という宣言にすぎない。会社の命運を賭ける施策を仮説のまま走らせることはできない——**腹を括るには、括るに足る数字が要る**。美咲が「沈んだ人」から「データで論じられる人」へ変わる転換の章。週次の時計の第1〜2週がそのまま背骨。

1. 仮説の言語化(第1週・傾向): 「アクセスは一様ではない。強い偏りがあるはずだ」——誰でも思いつく仮説を、経営に出せる数字にする作業として描く(エンジニア読者の必見パート)。三つの道具を重ねる:
   - **ストレージクラス分析**(第一章で仕込み済み・3週分): アップロード後30日でアクセスが崖になる——だが「ベータの動画だけ」のデータ。
   - **S3インベントリ**: 全オブジェクトの年齢・サイズ・クラスの棚卸し。三年分の写真の山の「形」が初めて見える(数億オブジェクト、中央値4MB、上位数%の大物が容量の過半——サイズの偏りも発見)。
   - **サーバーアクセスログの集計**(Athenaで叩く——道具として一行で登場させ、深掘りしない。S5への種): 写真3年分の「読まれ方の地図」。30日崖は写真でも成立、さらに動画はベータ3週分で**写真より崖が急**(挙式動画は二週間で見られ、その後ほぼ開かれない)。
2. 外挿の誠実さ: 「GA後の一般ユーザーも同型か?」に対し、根拠(写真3年の実績と動画ベータの一致)と限界(ベータは招待制=熱量の高いユーザーに偏る)を両方経営会議に出す。**外れた場合に最初に気づく仕組みが要る**——「それは、入れます。詳しくは走り出してから」の一言だけ置く(詳述しない。青柳・S8への伏線)。腹括りの瞬間: 経営層の承認はオフページ、美咲が会議室を出るところだけ書く。
3. 第2週(確定)——設計判断の連打(主導は美咲、瀬名は問いと検算。**裏で根回し**: 横槍が美咲に届かない。直接詰めるのは城戸だけ——不自然さに美咲はまだ気づかない):
   - 原本30日→**Standard-IA**(**取り出し料金**との損益分岐を城戸と検算——「読まれ方の地図」がそのまま分岐計算の入力になる)。
   - サムネイル→**One Zone-IA**(再生成可能だから。原本は絶対に置かない)。
   - 実装は**ライフサイクルポリシー**。
   - 金曜夜の自力回避: **最小ストレージ期間**30日×ストーリー機能7日削除の罠に、本番投入直前に自分で気づく(「移すだけ損や」維持)。
   - 法人プラン→**Intelligent-Tiering**(学校・式場は地図が描けない=読まれ方が契約・季節でバラバラ、を地図の「描けなかった領域」として示してから出す。監視料金と128KB未満の除外、4MB平均で成立する計算)。
4. 各自の+α: 守屋の棚卸し(持ち主なきバケット群、数TB即時削減)/狩野の私学商談転換(「三十年もちますか」はここ)/青柳の面接カメオ。
5. 章末: ライフサイクル一式は入った。数字は半減にあと一歩届かない——そして全員が知っている。**残っているのは、最初から分かっていた一番重い行李**(第四章へ。唐突ではなく、約束された対面)。

### 第四章 十二時間(約4,500字)— 総力戦・後半と、危機の中の危機

1. 一番重い行李との対面: 第3週、ライフサイクルを入れ切った直後の疲れの中で、後回しにしてきた7年保管データ(式場納品+退会者の保管約束)に向き合う。インベントリで見るとその山は容量の三割超——だが「7年、即時に開ける」前提ではIAでも数字が立たない。美咲が初めて挫けかける(「設計では、約束そのものは軽くならへん」)。
2. **狩野の助け舟(法務が技術の選択肢を開く)**: 「契約が約束しているのは『7年残っていること』。『7年、いつでも即座に開けること』じゃない。取り出しに時間を要する旨を規約に明記して、既存顧客には通知と同意を取る。——約束の言葉を正確にすれば、置き方は変えられるはずよ」。再定義が**Glacier Deep Archive**を解禁する(最小180日、標準取り出し12時間/バルク48時間、**取り出しオプション**の対応表を、規約に書く取り出しSLAと突き合わせて確定)。
3. 城戸の検算が設計を鍛える: 数億オブジェクトの**移行リクエスト課金**+Glacier系のオブジェクトあたり約40KBのメタデータ→小物の直行は損。tar固め+サイズフィルタ(「倉庫代より梱包代が高うつく引っ越しはあきません」)。
4. **誤投入事件**(クライマックス・第4週=テスト週の罠): ライフサイクル一式はStagingで1週間試験し、全件正常。だが**Stagingには本番3年分のプレフィックスの多様性がなかった**(初期移行ツールが残した旧形式のプレフィックスは、綺麗なテストデータに存在しない)。本番適用後、旧形式に巻き込まれた現役の七五三アルバムがDeep Archiveへ。標準取り出し12時間、Deepに特急便はない。経営危機の渦中に顧客の信頼問題が重なる——手に汗の最深部。第一章の単価見逃しと同じ根(Stagingは本番ではない)であることを、美咲自身に言わせる。
   - 美咲の責任の引き受け(「私が書いたバッチです。レビューは通していません」)。
   - 狩野の顧客対応(「写真は失われていません」を最初に置く文面)。
   - 瀬名が残って付き合う夜(「待つことしかできない夜、というのがある」——2011年は語らない)。
   - 「一家族だけの障害」を伝える型がない、という発見。
5. 失敗の翌朝: 一文字の修正で終わらせず、二人目承認+本番サンプリングでの事前検証(Stagingを信用しすぎない)の仕組みに作り替える。三つの教訓。このあたりで一瞬だけ、瀬名の根回しが見える(会議室から出てくる瀬名と経営層、途切れる会話——説明しない)。
6. 風間の点検メール(三行)で章を閉じる(東京拠点の存在と監査の目=後続シーズンへの糸)。

### 第五章 公開の朝(約3,500字)— デッドラインと静けさ

1. 動画一般公開当日: オフィス全員が同じダッシュボードを見ている。アップロード成功率(マルチパートの成果)、転送単価(TAの成果)、保存は新しい置き方で積まれていく。山は越える——派手な勝利ではなく、「想定の範囲に収まり続ける数字」の安堵として描く。
2. 月次の答え合わせ: 城戸の外挿グラフが引き直される——逆転点が消えている。「成長しても、死なん会社になりました。今月のところは」。**四つの質問**(頻度・待てる時間・再作成可否・保持の約束)を美咲が報告書に書く。
3. 私学商談の決着(「説明できる会社」が決め手)を狩野が短く共有。
4. 瀬名と美咲の対話: シリーズの問い「それは本当に戻せるんですか」の誕生(維持)。城戸がぽろりと明かす——「この六週間、堂島さんに横槍が一本も入らんかったでしょう。あれ、自然現象と違いますよ」。瀬名は何も言わない。瀬名のスマホに東京からの着信(出ない。説明しない)。東雲買収の噂。
5. 静けさで閉じる: 報告書の最後の一行(「請求書は嘘をつかない。正しく設計された請求書は、約束の履行記録になる」)→宿題リスト(配信設計「いつか」・高知・東雲)→汽笛→「明日も、写真は増える。約束も増える」。

## 書いてはいけないこと

- 「前月比180%」級の派手で不正確な跳ね方(急性は単価2.4倍・総額数%の「小さな違和感」で立てる)。
- バズの煽情的描写(トレンド入りの狂騒等)。ダッシュボードの傾き・招待待ちの人数・静かなオフィスの温度差で語る。
- 「全部Standardだったことを誰も知らなかった」式の無知設定(全員が知っていた。前提が変わっただけ)。
- 瀬名が答えを先回りする・執行の主導権を握る(問いと検算と根回しに徹する。悔いは第二章で一度だけ)。
